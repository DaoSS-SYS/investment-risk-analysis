# ADR-0009. Безрисковая ставка и коэффициенты эффективности

- **Статус:** принято
- **Дата:** 2026-09-23

## Контекст

Коэффициенты Шарпа, Сортино и Трейнора, а также модель CAPM требуют задания
безрисковой ставки. От её величины зависит знак и значение всех перечисленных
показателей, поэтому выбор источника требует обоснования.

## Решение по безрисковой ставке

В качестве безрисковой принимается **ключевая ставка Банка России**.

Основания выбора:

- ключевая ставка является официальным ориентиром стоимости денег в рублях,
  устанавливается Советом директоров Банка России и публикуется в открытом
  доступе;
- значения доступны через службу DailyInfoWebServ на каждый рабочий день,
  что позволяет загрузить сопоставимый по длине ряд;
- альтернативный ориентир — доходность облигаций федерального займа —
  потребовал бы выбора конкретного выпуска и учёта его срока до погашения,
  что вводит дополнительные допущения.

Расчёты ведутся по логарифмическим доходностям, поэтому годовая ставка
приводится к дневной логарифмической величине:

    rf(дн.) = ln(1 + rf(год)) / 252.

За период, охватывающий несколько лет, принимается среднее значение ставки по
рабочим дням периода. За период с 23.09.2016 по 22.09.2026 ключевая ставка
изменялась от 4,25 % до 21,00 % годовых, среднее значение составило **10,56 %**.

При отсутствии данных в базе применяется значение по умолчанию из
конфигурации. Наличие запасного значения обеспечивает работоспособность
расчётной части при недоступности внешнего источника.

## Решение по соотношению коэффициентов Шарпа и Сортино

Отклонение вниз рассчитывается как корень из второго нижнего частного момента:

    σ(вниз) = √( (1/n) · Σ min(0; r − MAR)² ),

где в знаменателе стоит **общее число наблюдений**, а не число отрицательных
отклонений. Определение соответствует исходной работе Ф. Сортино и
обеспечивает сопоставимость коэффициента для рядов с различной долей
убыточных периодов.

При таком определении справедливо строгое утверждение: **при неотрицательной
избыточной доходности коэффициент Сортино не может оказаться ниже коэффициента
Шарпа.**

Доказательство. Пусть X = r − MAR. Тогда σ² = E[X²] − (E[X])², а квадрат
отклонения вниз равен E[X²·1{X<0}]. Отсюда

    DD² = σ² + (E[X])² − E[X²·1{X>0}].

По неравенству Коши — Буняковского

    (E[X])² ≤ (E[X·1{X>0}])² ≤ E[X²·1{X>0}],

где первое неравенство следует из E[X] ≤ E[X·1{X>0}]. Следовательно DD² ≤ σ²,
что и требовалось.

Практическое следствие: распространённое утверждение о том, что превышение
коэффициента Шарпа над коэффициентом Сортино свидетельствует об отрицательной
асимметрии распределения, для данного определения **неверно**. Содержательной
характеристикой служит величина превышения коэффициента Сортино: чем она
меньше, тем большую долю общего разброса доходности составляют отклонения
вниз.

Утверждение выявлено при разработке: соответствующий модульный тест не
проходил, и разбор показал, что ошибочным было предположение теста, а не
реализация.

## Решение по модели CAPM

Параметры оцениваются методом наименьших квадратов по уравнению

    r(i) − rf = α + β · (r(m) − rf) + ε.

Одновременно рассчитываются стандартные ошибки оценок и t-статистики. Оценка
альфы обладает значительной стандартной ошибкой, поэтому вывод о наличии
доходности сверх обусловленной рыночным риском без проверки значимости
не обоснован.

Доля систематического риска рассчитывается двумя независимыми способами —
через разложение дисперсии β²·σ²(рынка) / σ²(инструмента) и как коэффициент
детерминации. Совпадение результатов служит проверкой согласованности расчёта
и закреплено модульным тестом.

Период с 23.09.2016 по 22.09.2026, безрисковая ставка 10,56 % годовых,
эталонный портфель — индекс МосБиржи.

Все коэффициенты Шарпа отрицательны: за рассмотренный период доходность
вложений в акции не покрыла безрисковую ставку. Из шести инструментов
восстановление после наибольшей просадки произошло только по обыкновенным

Оценки коэффициента бета статистически значимы с большим запасом. **Альфа
Йенсена не значима ни по одному инструменту**: ни одна из рассмотренных бумаг
не обеспечила доходности сверх обусловленной принятым систематическим риском.
Результат согласуется с представлением об информационной эффективности рынка
и подтверждает необходимость проверки значимости: без неё альфа SBER в 5,08 %
годовых была бы ошибочно истолкована как избыточная доходность.

Движением рынка объясняется от 33,5 % до 58,8 % дисперсии доходности
инструментов; остальное приходится на специфический риск, устранимый
диверсификацией.

Корреляционный анализ пяти акций, 2509 наблюдений общего торгового календаря:
средняя парная корреляция 0,554, волатильность равновзвешенного портфеля
26,65 % против средневзвешенной волатильности составляющих 33,17 %.
**Диверсификация снижает риск на 19,7 %.**

## Последствия

Положительные:

- оценка эффективности выполняется относительно официального ориентира
  стоимости денег, а не произвольно заданной величины;
- проверка значимости альфы предотвращает необоснованные выводы;
- количественная оценка эффекта диверсификации подготавливает переход
  к оптимизации структуры портфеля.

Отрицательные и известные ограничения:

- среднее значение ключевой ставки за период сглаживает её изменение от
  4,25 % до 21,00 %; для оценок на коротких подпериодах следует применять
  ставку соответствующего подпериода;
- модель CAPM однофакторна и объясняет от трети до трёх пятых дисперсии
  доходности; многофакторные модели в работе не рассматриваются;
- доходность рассчитывается по ценовому ряду без учёта дивидендов, что
  занижает полную доходность вложения и, соответственно, коэффициенты
  эффективности (см. [ADR-0007](0007-korporativnye-dejstviya.md)).
