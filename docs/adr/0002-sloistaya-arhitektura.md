# ADR-0002. Многослойная архитектура с изолированным расчётным ядром

- **Статус:** принято
- **Дата:** 2026-09-23

## Контекст

Система решает две разнородные задачи: автоматизацию сбора и хранения биржевых
данных и количественную оценку риска по математическим моделям. Вторая задача
составляет научную основу работы: реализованные модели подлежат проверке на
корректность и сравнению между собой по результатам апробации на реальных
данных.

Размещение расчётных алгоритмов внутри контроллеров или сервисов, работающих с
базой данных, сделало бы их проверку невозможной без развёрнутой СУБД и
затруднило бы изложение алгоритмов в тексте работы как самостоятельного
компонента системы.

## Решение

Решение разделяется на пять проектов со строго заданным направлением
зависимостей:

| Проект | Назначение | Зависимости |
| --- | --- | --- |
| `RiskAnalysis.Domain` | Сущности предметной области | нет |
| `RiskAnalysis.RiskEngine` | Расчётное ядро: математические модели оценки риска | только `MathNet.Numerics` |
| `RiskAnalysis.Application` | Сценарии использования, интерфейсы, объекты передачи данных | `Domain`, `RiskEngine` |
| `RiskAnalysis.Infrastructure` | Доступ к данным, клиенты внешних источников | `Domain`, `Application` |
| `RiskAnalysis.WebApi` | Программный интерфейс, аутентификация, документация | `Application`, `Infrastructure` |

Ключевое ограничение: проект `RiskAnalysis.RiskEngine` не зависит ни от базы
данных, ни от инфраструктуры доступа к сети, ни от доменных сущностей. Он
принимает на вход массивы числовых значений и возвращает результаты расчёта.

## Последствия

Положительные:

- расчётное ядро полностью покрывается модульными тестами на эталонных примерах
  без развёртывания СУБД;
- ядро описывается в работе как самостоятельный компонент системы;
- замена источника данных или пользовательского интерфейса не затрагивает
  математические модели.

Отрицательные:

- требуется преобразование доменных сущностей в массивы значений на границе
  слоя приложения;
- пять проектов вместо одного усложняют начальную настройку решения.
