# ADR-0008. Методы оценки стоимостной меры риска

- **Статус:** принято
- **Дата:** 2026-09-23

## Контекст

Проверка по критерию Жарка — Бера (см. этап 3) показала, что гипотеза о
нормальности распределения доходностей отвергается по всем рассмотренным
инструментам. Параметрический метод оценки стоимостной меры риска основан
именно на этом предположении, вследствие чего применение единственного метода
не обеспечивает достоверной оценки.

## Решение

Реализуются три метода оценки, применяемые одновременно к одной выборке:

1. **Параметрический (дельта-нормальный).** Квантиль распределения выражается
   через среднее и среднеквадратическое отклонение. Ожидаемые потери
   рассчитываются по замкнутой формуле. Метод сохранён не как основной, а как
   база сравнения: его отклонение от остальных методов количественно выражает
   влияние предположения о нормальности.

2. **Историческое моделирование.** Оценкой служит выборочный квантиль
   фактически наблюдавшихся доходностей. Предположения о виде распределения
   не вводятся.

3. **Метод Монте-Карло** в трёх вариантах закона распределения:
   - нормальное — служит проверкой корректности реализации: оценка должна
     сходиться к параметрической;
   - распределение Стьюдента с числом степеней свободы, оцениваемым по
     наблюдаемому коэффициенту эксцесса из соотношения ν = 4 + 6 / g₂;
   - историческая бутстрэп-выборка — сценарии формируются случайным выбором
     из фактически наблюдавшихся доходностей.

**Моделирование взаимосвязанных доходностей.** Требуемая структура взаимосвязей
воспроизводится разложением Холецкого ковариационной матрицы: Σ = L · Lᵀ. Если
z — вектор независимых стандартных величин, то вектор L · z обладает
ковариационной матрицей Σ. Независимое моделирование доходностей занизило бы
риск портфеля за счёт мнимого эффекта диверсификации.

Бутстрэп-выборка сохраняет взаимосвязи иначе: выбирается торговый день целиком,
со всеми доходностями инструментов за этот день.

**Ожидаемые потери.** Рассчитываются одновременно со стоимостной мерой риска.
Стоимостная мера риска указывает границу потерь, но не их величину при
превышении этой границы; ожидаемые потери усредняют весь «хвост». Базельский
комитет в стандарте FRTB заменил стоимостную меру риска ожидаемыми потерями
именно по этой причине.

**Горизонт оценки.** Пересчёт на горизонт в h торговых дней выполняется по
правилу корня из времени: среднее умножается на h, среднеквадратическое
отклонение — на корень из h. Правило вытекает из предположения о независимости
доходностей смежных периодов, предусмотрено требованиями Базельского комитета
и применяется единообразно во всех методах, что обеспечивает сопоставимость
оценок.

**Воспроизводимость.** Метод Монте-Карло использует генератор псевдослучайных
чисел Mersenne Twister с задаваемым начальным значением. Повторный запуск
с теми же параметрами даёт тот же результат, что необходимо для проверки
расчётов и требуется при сохранении результатов в журнале расчётов
(см. [ADR-0005](0005-hranenie-parametrov-raschetov.md)).

## Результаты апробации

Выборка: 2513 дневных логарифмических доходностей за период с 23.09.2016 по
22.09.2026, позиция 1 000 000 рублей, горизонт один торговый день.

Отношение оценки методом исторического моделирования к параметрической оценке
по обыкновенным акциям ПАО Сбербанк:

| Уровень доверия | Отношение по VaR | Отношение по CVaR |
| ---: | ---: | ---: |
| 90,0 % | 0,694 | 0,964 |
| 95,0 % | 0,773 | 1,138 |
| 97,0 % | 0,902 | 1,298 |
| 98,0 % | 0,966 | 1,436 |
| 98,5 % | 1,071 | 1,562 |
| 99,0 % | 1,161 | 1,725 |
| 99,5 % | 1,219 | 2,184 |

Полученная зависимость соответствует форме фактического распределения
доходностей, установленной на этапе 3: распределение более сосредоточено
в центральной области и обладает более «тяжёлыми хвостами», чем нормальное.

Следствием является вывод, определяющий порядок применения методов:
**параметрический метод завышает оценку риска при умеренных уровнях доверия и
занижает её при высоких.** Для стоимостной меры риска переход происходит вблизи
уровня 98,2 %, для ожидаемых потерь — вблизи 92 %. При уровне доверия 99 %,
предусмотренном требованиями Базельского комитета, параметрический метод
занижает ожидаемые потери в 1,7 раза.

## Последствия

Положительные:

- сопоставление методов образует содержательный результат работы, а не
  перечень реализованных алгоритмов;
- оценка ожидаемых потерь соответствует действующим требованиям к оценке
  рыночного риска;
- совпадение оценки методом Монте-Карло при нормальном законе с
  параметрической оценкой служит проверкой корректности моделирования.

Отрицательные и известные ограничения:

- правило корня из времени предполагает независимость доходностей смежных
  дней; при наличии кластеризации волатильности оценка на горизонте свыше
  одного дня занижается. Устранение требует моделей условной волатильности —
  предусмотрено на последующих этапах (EWMA);
- метод исторического моделирования учитывает все наблюдения с равными весами
  и медленно реагирует на изменение рыночных условий;
- точность оценки квантиля уровня 99 % ограничена объёмом выборки: при 2513
  наблюдениях в «хвосте» находятся лишь 25 значений;
- достоверность самого вывода о занижении подлежит проверке бэктестированием —
  предусмотрено на этапе 8.
