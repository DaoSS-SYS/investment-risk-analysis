# ADR-0012. Модели условной волатильности

- **Статус:** принято
- **Дата:** 2026-09-25

## Контекст

Бэктестирование, выполненное на этапе 8, выявило устойчивую причину
непригодности реализованных моделей: гипотеза о независимости нарушений
отвергается в восьми сочетаниях из девяти. Нарушения группируются во времени,
сосредоточиваясь в периодах повышенной волатильности.

Причина установлена: параметрический метод, метод исторического моделирования
и метод Монте-Карло опираются на **безусловную** оценку волатильности —
выборочное среднеквадратическое отклонение, одинаковое для спокойных и
кризисных периодов. Все наблюдения окна учитываются с равными весами, поэтому
оценка запаздывает: после рыночного шока она растёт медленно, а после
завершения периода потрясений столь же медленно снижается.

Данное решение устраняет установленную причину.

## Решение

Реализуются три метода, опирающиеся на условную оценку волатильности.

**Экспоненциально взвешенная оценка (EWMA).** Веса наблюдений убывают
в геометрической прогрессии по мере удаления в прошлое:

    σ²(t) = λ · σ²(t−1) + (1 − λ) · r²(t−1),

что равносильно σ²(t) = (1 − λ) · Σ λ^k · r²(t−1−k). Очередное наблюдение
входит в оценку с весом 1 − λ, поэтому реакция на изменение рыночных условий
наступает немедленно. Принято значение λ = 0,94, установленное методикой
RiskMetrics для дневных данных; ему соответствует период полураспада веса
11,2 торгового дня.

**Модель GARCH(1,1).** В отличие от экспоненциально взвешенной оценки
содержит постоянную составляющую:

    σ²(t) = ω + α · r²(t−1) + β · σ²(t−1).

Благодаря ей модель обладает свойством возврата к долгосрочному уровню
волатильности σ²(∞) = ω / (1 − α − β), тогда как экспоненциально взвешенная
оценка даёт на любом горизонте прогноз, равный текущему значению.

Параметры оцениваются методом максимального правдоподобия при условной
нормальности доходностей. Максимизация выполняется численно методом
деформируемого многогранника Нелдера — Мида. Ограничения ω > 0, α ≥ 0,
β ≥ 0, α + β < 1 обеспечиваются заменой переменных: ω = exp(p₀),
α = s(p₁) · c, β = s(p₂) · (c − α), где s — логистическая функция,
c = 0,999. Оптимизация ведётся по неограниченным величинам, вследствие чего
ограничения выполняются тождественно при любом значении аргумента.

**Фильтрованное историческое моделирование.** Соединяет условную оценку
волатильности с эмпирическим распределением:

1. доходности делятся на соответствующие им условные волатильности,
   что даёт ряд стандартизованных величин z(t) = r(t) / σ(t);
2. квантиль оценивается по эмпирическому распределению этих величин,
   то есть без предположения о его виде — «тяжёлые хвосты» сохраняются;
3. полученный квантиль умножается на прогноз волатильности.

Тем самым одновременно учитываются изменчивость волатильности и отклонение
распределения доходностей от нормального — два свойства, каждое из которых
по отдельности приводило к отклонению модели при бэктестировании.

## Результаты апробации

Обыкновенные акции ПАО Сбербанк, период с 23.09.2016 по 22.09.2026,
2263 проверенных наблюдения. Критическое значение критерия независимости —
3,841.

**Статистика критерия независимости нарушений:**

| Конфигурация | Параметрич. | Историч. | Монте-Карло | EWMA | GARCH(1,1) | Фильтр. историч. |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 99 %, окно 250 | 6,22 ✗ | 1,66 | 12,42 ✗ | **1,53** | **1,95** | **1,04** |
| 99 %, окно 500 | 5,13 ✗ | 4,31 ✗ | 4,84 ✗ | **1,93** | **0,27** | **0,52** |
| 95 %, окно 250 | 20,46 ✗ | 14,09 ✗ | 20,46 ✗ | **0,49** | **0,97** | **2,63** |

Знаком ✗ отмечены случаи отклонения гипотезы о независимости.

**Основной результат: для моделей с безусловной оценкой волатильности
гипотеза о независимости нарушений отвергается в восьми сочетаниях из девяти,
для моделей с условной оценкой — ни в одном из девяти.**

Наиболее показательно сопоставление при уровне доверия 95 % и окне 250
наблюдений: статистика критерия снижается с 20,46 у параметрического метода
до 0,49 у метода с экспоненциально взвешенной оценкой, то есть более чем
в сорок раз. Группирование нарушений устранено.

**Полные результаты при уровне доверия 95 %, окно 250 наблюдений**
(ожидается 113,2 нарушения):

| Метод | Нарушений | Доля | Купец | Независимость | Условное покрытие | Вывод |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| Параметрический | 101 | 4,46 % | 1,42 | 20,46 ✗ | 21,88 ✗ | отвергнут |
| Исторический | 126 | 5,57 % | 1,48 | 14,09 ✗ | 15,58 ✗ | отвергнут |
| Монте-Карло | 101 | 4,46 % | 1,42 | 20,46 ✗ | 21,88 ✗ | отвергнут |
| **EWMA** | 101 | 4,46 % | 1,42 | 0,49 | **1,92** | **принят** |
| **GARCH(1,1)** | 95 | 4,20 % | 3,23 | 0,97 | **4,20** | **принят** |
| Фильтр. историч. | 137 | 6,05 % | 4,97 ✗ | 2,63 | 7,60 ✗ | отвергнут |

Критическое значение критерия условного покрытия — 5,991.

Обращает на себя внимание, что все модели с безусловной оценкой волатильности
проходят критерий Купца: частота нарушений согласуется с заявленным уровнем
доверия. Их отклонение вызвано исключительно группированием нарушений.
Применение одного лишь критерия Купца привело бы к ошибочному признанию этих
моделей пригодными.

## Сохраняющееся ограничение при уровне доверия 99 %

При уровне доверия 99 % критерий Купца отвергает все модели, кроме метода
исторического моделирования с окном 500 наблюдений: фактическая доля
нарушений составляет от 1,24 до 2,12 процента при ожидаемой 1,00 процента.
Переход к условной волатильности снижает число нарушений — у метода
фильтрованного исторического моделирования с 45 до 34 при окне 250 — но
не доводит его до ожидаемого уровня.

Вероятная причина состоит в ограниченности выборки: при окне 250 наблюдений
уровню доверия 99 процентов соответствуют лишь 2,5 наблюдения в «хвосте»
распределения, что недостаточно для устойчивой оценки квантиля. Проверка этого
предположения требует увеличения глубины окна при сохранении достаточной
длины периода проверки и относится к направлениям дальнейшего развития.

## Практические выводы

1. При уровне доверия 95 процентов пригодны параметрический метод с
   экспоненциально взвешенной оценкой волатильности и метод с моделью
   GARCH(1,1); методы с безусловной оценкой волатильности непригодны,
   несмотря на соответствие частоты нарушений заявленному уровню.
2. При уровне доверия 99 процентов из проверенных моделей пригоден метод
   исторического моделирования с глубиной окна 500 наблюдений.
3. Применение критерия Купца без критерия Кристоферсена недостаточно:
   в шести сочетаниях из восемнадцати проверенных модель, прошедшая критерий
   Купца, отвергается по критерию независимости.

## Последствия

Положительные:

- установленная на этапе 8 причина непригодности моделей устранена, что
  подтверждено тем же критерием, которым она была выявлена;
- получен воспроизводимый результат: восемь отклонений из девяти против нуля
  из девяти при прочих равных условиях;
- реализовано оценивание параметров модели GARCH методом максимального
  правдоподобия, а не вызовом готовой библиотеки.

Отрицательные и известные ограничения:

- при уровне доверия 99 процентов частота нарушений остаётся выше ожидаемой
  у всех моделей с условной оценкой волатильности;
- оценивание параметров модели GARCH выполняется методом прямого поиска,
  не использующим производных; при отсутствии сходимости применяются
  начальные приближения, соответствующие типичным для доходностей акций
  значениям;
- условная нормальность, принятая в функции правдоподобия модели GARCH, не
  выполняется; более точным было бы предположение о распределении Стьюдента,
  что относится к направлениям дальнейшего развития.
