# ADR-0006. Источник рыночных данных и идемпотентная загрузка

- **Статус:** принято
- **Дата:** 2026-09-23

## Контекст

Исходными данными для всех расчётов служат исторические котировки
финансовых инструментов. Требования к источнику:

- открытость и отсутствие платы за доступ;
- достаточная глубина истории — не менее десяти лет, чтобы выборка охватывала
  несколько рыночных циклов, включая кризисные периоды 2020 и 2022 годов;
- официальный статус: данные должны быть пригодны для ссылки в тексте
  выпускной квалификационной работы.

## Решение

В качестве основного источника принят информационно-статистический сервер
Московской Биржи (MOEX ISS, `https://iss.moex.com/iss/`). Доступ не требует
аутентификации.

Особенности реализации клиента:

1. **Разбор по именам столбцов.** Ответ сервера имеет табличную структуру:
   массив имён столбцов `columns` и массив строк `data`. Состав и порядок
   столбцов различаются по рынкам — для рынка акций и для рынка индексов они
   не совпадают. Поэтому значения извлекаются по имени столбца, а не по его
   порядковому номеру.
2. **Постраничная выдача.** Сервер возвращает не более 100 записей за запрос;
   общее число записей и размер страницы сообщаются в служебном блоке
   `history.cursor`. Десятилетняя история одного инструмента требует около
   25 запросов. Между запросами выдерживается пауза, ограничивающая
   интенсивность обращений к публичному источнику.
3. **Повторные попытки.** При кодах ответа 5xx и 429, ошибках передачи и
   превышении времени ожидания запрос повторяется с нарастающей задержкой.
   Ошибки, не являющиеся временными, повтору не подлежат.

Дополнительным источником служат открытые сервисы Банка России: ключевая
ставка используется в качестве безрисковой ставки при расчёте коэффициентов
Шарпа, Сортино, Трейнора и параметров модели CAPM.

## Идемпотентность загрузки

Загрузка котировок за один и тот же период выполняется многократно: по
расписанию, при ручном запуске и при довыгрузке недостающих данных. Кроме
того, биржа пересматривает итоги торгов последних дней.

Идемпотентность обеспечивается на двух уровнях:

- на уровне базы данных — уникальным индексом по паре «инструмент — дата
  торгов», который исключает появление дубликатов;
- на уровне приложения — сопоставлением полученных записей с уже имеющимися:
  отсутствующие добавляются, изменившиеся обновляются, совпадающие
  пропускаются.

Каждый сеанс загрузки фиксируется в таблице `import_logs` с указанием числа
полученных, добавленных и обновлённых записей, результата и длительности.

## Автономность работы

Все котировки сохраняются в базе данных, и расчёты выполняются исключительно
по сохранённым данным. Обращение к внешнему источнику происходит только на
этапе загрузки. Система сохраняет работоспособность при недоступности
внешнего источника, что является обязательным условием демонстрации.

## Последствия

Положительные:

- источник официален, открыт и допускает ссылку в тексте работы;
- журнал загрузок служит подтверждением полноты исходных данных;
- отказ внешнего источника не препятствует работе расчётной части.

Отрицательные:

- источник публикует котировки без корректировки на корпоративные действия
  (дробление и консолидация акций), что требует отдельного этапа
  предобработки данных — см. [ADR-0007](0007-korporativnye-dejstviya.md);
- система привязана к российскому рынку; добавление зарубежных площадок
  потребует новой реализации интерфейса `IMarketDataClient`.
