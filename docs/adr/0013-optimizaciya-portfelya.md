# ADR-0013. Оптимизация структуры портфеля по модели Марковица

- **Статус:** принято
- **Дата:** 2026-09-25

## Контекст

Разработанные ранее средства отвечают на вопрос о величине риска заданного
портфеля и о вкладе в него отдельных позиций. Вопрос о том, какой должна быть
структура вложений, остаётся неохваченным.

Модель Марковица формулирует его следующим образом: отыскать структуру,
при которой для заданного уровня ожидаемой доходности дисперсия минимальна.
Совокупность таких портфелей образует эффективную границу.

## Постановка задачи

Рассматривается задача с ограничениями

    Σ w(i) = 1,    0 ≤ w(i) ≤ w(max),

то есть без коротких продаж и с предельной долей одного инструмента.
Запрет коротких продаж соответствует условиям деятельности большинства
инвесторов. Ограничение доли введено по результатам апробации — обоснование
приведено ниже.

## Решение: параметризация границы по коэффициенту неприятия риска

Эффективная граница строится не перебором целевых уровней доходности, а
параметризацией по коэффициенту неприятия риска γ: для каждого значения γ
решается задача

    max [ wᵀ · μ − (γ / 2) · wᵀ · Σ · w ]    при Σ w(i) = 1, 0 ≤ w(i) ≤ w(max).

При γ → 0 решением является портфель наибольшей доходности, при γ → ∞ —
портфель наименьшей дисперсии; промежуточные значения дают промежуточные
точки границы.

Основание выбора. Постановка с ограничением на целевую доходность
(min wᵀΣw при wᵀμ = μ*) требует проверки достижимости каждого значения μ*
и содержит два линейных ограничения помимо ограничений на область значений.
Параметризация по γ приводит задачу к виду, содержащему только ограничения
на область допустимых значений, что существенно упрощает численное решение.

Значения γ распределены по логарифмической шкале: при равномерном шаге точки
сгущались бы у одного конца границы.

## Решение: метод проекции градиента

Задача представляет собой квадратичное программирование с ограничениями.
Применяется метод проекции градиента: на каждом шаге выполняется шаг в
направлении антиградиента, после чего полученная точка проецируется на
область допустимых значений.

Проекция на множество { w : Σ w(i) = 1, 0 ≤ w(i) ≤ w(max) } имеет вид

    w(i) = clamp(v(i) − θ, 0, w(max)),

где θ выбирается из условия равенства суммы единице. Сумма монотонно убывает
по θ, поэтому θ отыскивается делением отрезка пополам. Такая форма проекции
охватывает оба случая — с ограничением доли сверху и без него.

Длина шага принимается равной величине, обратной константе Липшица градиента,
равной γ, умноженному на наибольшее собственное число ковариационной матрицы.
При таком выборе метод сходится для любой выпуклой задачи рассматриваемого
вида.

Рассмотренная и отклонённая альтернатива: отбор наилучшего из множества
портфелей со случайной структурой. Способ прост в реализации, однако при
числе инструментов свыше пяти требует неприемлемо большого числа испытаний
для достижения приемлемой точности, а полученное решение не является точным.
Портфели со случайной структурой сохранены, но не как способ решения, а как
наглядное представление области допустимых сочетаний доходности и риска.

## Результаты апробации

Модельный портфель из пяти акций, период с 23.09.2016 по 22.09.2026,
2509 наблюдений общего торгового календаря, безрисковая ставка 10,56 %
годовых.

**Без ограничения предельной доли:**

| Портфель | Доходность | Риск | Коэффициент Шарпа |
| --- | ---: | ---: | ---: |
| Текущая структура | 2,50 % | 26,68 % | −0,283 |
| Наименьшая дисперсия | 3,54 % | 25,86 % | −0,252 |
| Касательный | 6,20 % | 33,70 % | −0,114 |

Структура портфеля наименьшей дисперсии: GMKN 37,6 %, LKOH 31,4 %,
SBER 18,3 %, GAZP 11,1 %, ROSN 1,6 %.

**Структура касательного портфеля: SBER 100 %.**

## Основной вывод апробации: вырождение касательного портфеля

Полученный результат — сосредоточение касательного портфеля в единственном
инструменте — представляет собой известное свойство модели Марковица,
проявившееся здесь в крайней форме.

Причина двойная.

Первая: за рассмотренный период доходность всех пяти инструментов оказалась
ниже безрисковой ставки (см. [ADR-0009](0009-bezriskovaya-stavka-i-koefficienty.md)),
то есть все избыточные доходности отрицательны. При отрицательных избыточных
доходностях максимизация коэффициента Шарпа сводится к отысканию инструмента
с наименьшими по модулю потерями относительно безрисковой ставки, и решение
сосредоточивается в нём.

Вторая: ожидаемые доходности оцениваются средними значениями по выборке.
Такая оценка обладает значительной дисперсией, и оптимизация, использующая
её, усиливает погрешность оценивания: инструмент со случайно завышенной
средней доходностью получает наибольшую долю.

Портфель наименьшей дисперсии этому недостатку не подвержен, поскольку
не использует оценок ожидаемой доходности вовсе — только ковариационную
матрицу, оцениваемую существенно точнее.

## Решение: ограничение предельной доли инструмента

Введено ограничение w(i) ≤ w(max). Влияние на структуру касательного
портфеля:

| Предельная доля | Структура касательного портфеля | Коэффициент Шарпа |
| --- | --- | ---: |
| без ограничения | SBER 100 % | −0,114 |
| 40 % | LKOH 40 %, SBER 40 %, GMKN 20 % | −0,182 |
| 30 % | GMKN 30 %, LKOH 30 %, SBER 30 %, ROSN 10 % | −0,218 |

Ограничение устраняет вырождение. Коэффициент Шарпа при этом снижается,
однако снижение относится к выборке, по которой выполнена оптимизация;
устойчивость решения вне выборки возрастает.

## Практические выводы

1. Для практического применения предпочтителен портфель наименьшей
   дисперсии: он не использует оценок ожидаемой доходности и потому
   устойчив.
2. Касательный портфель следует рассчитывать только с ограничением
   предельной доли инструмента.
3. Переход текущей структуры портфеля к структуре наименьшей дисперсии
   снижает волатильность с 26,68 % до 25,86 % годовых, то есть на 3,1 %,
   при одновременном повышении ожидаемой доходности с 2,50 % до 3,54 %.

## Последствия

Положительные:

- решение получено методом выпуклой оптимизации, а не перебором, и является
  точным в пределах заданной точности сходимости;
- ограничение предельной доли позволяет получать пригодные к применению
  решения при неустойчивых оценках ожидаемой доходности;
- множество портфелей со случайной структурой даёт наглядное подтверждение
  корректности границы: ни один из трёх тысяч случайных портфелей не
  расположен выше неё.

Отрицательные и известные ограничения:

- оценки ожидаемой доходности по средним значениям выборки неустойчивы;
  устранение требует применения устойчивых оценок ковариационной матрицы
  (сжатие по Ледуа — Вольфу) либо модели Блэка — Литтермана, что относится
  к направлениям дальнейшего развития;
- модель исходит из того, что инвестор оценивает портфель средним значением
  и дисперсией доходности; при отклонении распределения от нормального,
  установленном на этапе 3, такое описание неполно;
- оптимизация выполняется по всему периоду наблюдений; структура портфеля,
  оптимальная на десятилетнем периоде, не является оптимальной на любом
  его подпериоде.
